# Salary auto command for JsMacros

`salary_auto.js` автоматически отправляет команду `/salary` каждые 30 минут, но **только после того, как вы сами один раз ввели `/salary`**.

## Как работает

1. Вы заходите в мир или на сервер.
2. Скрипт ничего не делает и не запускает таймер.
3. Вы вручную вводите `/salary`.
4. Скрипт пишет в чат жирное сообщение `СКРИПТ АВТО ЗАРПЛАТА ВКЛЮЧЕН`.
5. Скрипт запускает отсчёт 30 минут.
6. После этого он сам отправляет `/salary` каждые 30 минут, пока вы находитесь в мире.
7. Если вы вышли из мира, автоматическая отправка отключается до следующего ручного ввода `/salary`.

## Установка

1. Установите мод [JsMacros](https://jsmacros.wagyourtail.xyz/).
2. Скопируйте `salary_auto.js` в папку скриптов JsMacros.
3. В меню JsMacros привяжите `salary_auto.js` к событию `SendMessage`.
4. Зайдите в мир или на сервер и один раз вручную напишите `/salary`.

## Настройка

Интервал задаётся в `salary_auto.js`:

```js
const INTERVAL_MS = 30 * 60 * 1000;
```

Команда задаётся там же:

```js
const COMMAND = '/salary';
```
